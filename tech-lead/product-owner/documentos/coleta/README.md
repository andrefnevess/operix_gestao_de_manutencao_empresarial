# Coleta com Usuários (F1)

Material para a coleta de requisitos com potenciais usuários: gestores, técnicos e solicitantes de manutenção. A coleta compõe a nota F1 (coleta + incubators).

| Documento | Uso |
|---|---|
| [roteiro-de-entrevista.md](roteiro-de-entrevista.md) | Entrevista de 15 a 20 minutos, por perfil |
| [questionario.md](questionario.md) | Questionário curto para aplicar em formulário online |
| [termo-de-consentimento.md](termo-de-consentimento.md) | Texto lido ou enviado antes da entrevista (LGPD) |
| [consolidacao.md](consolidacao.md) | Modelo para registrar e consolidar os resultados |

## Como conduzir

1. Selecionar de 3 a 5 participantes, de preferência com perfis diferentes (gestor, técnico, solicitante);
2. Apresentar o termo de consentimento;
3. Aplicar o roteiro, anotando as respostas sem nome nem dado pessoal;
4. Registrar cada entrevista em `consolidacao.md` com um código (P1, P2...);
5. Ao final, consolidar os achados e ajustar o backlog (histórias e prioridades).

> Responsável: André Neves (Product Owner). Os resultados devem vir de entrevistas reais; nada deve ser preenchido com dados inventados.
