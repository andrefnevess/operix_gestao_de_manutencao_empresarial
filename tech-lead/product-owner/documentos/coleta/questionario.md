# Questionário (formulário online)

Versão curta do roteiro, para aplicar em um formulário (Google Forms ou similar). Não pedir nome nem e-mail.

| Nº | Pergunta | Tipo de resposta |
|---|---|---|
| 1 | Qual é a sua função em relação à manutenção? | Gestor / Técnico / Solicitante / Outro |
| 2 | Tipo de organização | Indústria / Comércio / Escola / Saúde / Condomínio / Outro |
| 3 | Como os problemas em equipamentos são comunicados hoje? | Múltipla escolha: WhatsApp, telefone, papel, e-mail, sistema, outro |
| 4 | O histórico de manutenção de cada equipamento fica registrado? | Sim, em sistema / Sim, em planilha ou papel / Não |
| 5 | Existem manutenções preventivas programadas? | Sim, e são cumpridas / Sim, mas atrasam / Não |
| 6 | Com que frequência uma solicitação se perde ou é esquecida? | Nunca / Raramente / Às vezes / Frequentemente |
| 7 | Qual o maior problema da manutenção hoje? | Texto curto |
| 8 | Quais funcionalidades seriam mais úteis? | Múltipla escolha: equipamentos, chamados, ordens de serviço, preventivas com alertas, histórico, indicadores |
| 9 | Onde você usaria o sistema? | Computador / Celular / Os dois |
| 10 | De 0 a 10, o quanto um sistema assim ajudaria? | Escala 0 a 10 |
