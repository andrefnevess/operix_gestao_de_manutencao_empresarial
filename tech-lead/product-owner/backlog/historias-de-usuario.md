# Histórias de Usuário Detalhadas

## US01 — Login

> Como usuário, quero fazer login, para acessar as funcionalidades do meu perfil.

**Critérios de aceitação**

- [ ] Login com e-mail e senha válidos redireciona para o painel;
- [ ] Credenciais inválidas exibem mensagem de erro sem indicar qual campo está errado;
- [ ] Usuário inativo não consegue acessar.

## US03 — Cadastro de ativos

> Como gestor, quero cadastrar ativos, para manter o inventário de equipamentos.

**Critérios de aceitação**

- [ ] Campos obrigatórios: código, nome, tipo e localização;
- [ ] Código do ativo deve ser único;
- [ ] Ativo pode ser editado e inativado.

## US05 — Abertura de ordem de serviço

> Como solicitante, quero abrir uma ordem de serviço, para reportar um problema em um ativo.

**Critérios de aceitação**

- [ ] A ordem deve estar vinculada a um ativo ativo;
- [ ] A ordem é criada com status ABERTA;
- [ ] O número da ordem é exibido ao solicitante.
