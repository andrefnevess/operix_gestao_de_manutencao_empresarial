## Variáveis de ambiente

| Variável | Descrição |
|---|---|
| `DB_URL` | URL de conexão com o banco |
| `DB_USER` | Usuário do banco |
| `DB_PASSWORD` | Senha do banco (nunca versionar) |
| `API_URL` | URL da API usada pelo front-end |
