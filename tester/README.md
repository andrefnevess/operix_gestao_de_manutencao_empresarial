# Tester / QA

Estratégia, planejamento, execução e evidências de testes.

| Pasta | Conteúdo |
|---|---|
| [planos-de-teste](planos-de-teste) | Planos de teste por sprint ou módulo |
| [casos-de-teste](casos-de-teste) | Casos de teste (`CT-NNN-descricao.md`) |
| [evidencias](evidencias) | Prints, vídeos e logs das execuções |
| [relatorios](relatorios) | Relatórios de execução e defeitos |

## Tipos de teste

- Unitários (back-end, JUnit);
- Integração (API);
- Funcionais / sistema (manuais, baseados nos casos de teste);
- Aceitação (validação dos critérios das histórias com o PO).

Defeitos encontrados devem ser registrados como Issue do tipo `[BUG]`.
