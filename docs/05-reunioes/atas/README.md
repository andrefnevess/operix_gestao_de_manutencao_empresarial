# Atas de Reunião

Cada reunião gera um arquivo próprio, seguindo o modelo [ATA-000-modelo.md](ATA-000-modelo.md). A partir da ATA-002 as reuniões são **quinzenais** (terças, 19h), com review, retrospectiva e planejamento da quinzena seguinte (DEC-012).

## Convenção de nomes

`ATA-NNN-assunto.md` — ex.: `ATA-002-reuniao-quinzenal-13-10.md`.
