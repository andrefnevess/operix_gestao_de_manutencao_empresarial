# Checklist de Conformidade

Verificação realizada ao final de cada sprint, antes da Sprint Review. Responsável pelo acompanhamento: Scrum Master.

## Repositório e acessos

- [ ] Repositório continua privado
- [ ] Lista de colaboradores revisada (somente equipe e professor)
- [ ] 2FA habilitado para todos os integrantes
- [ ] Branch `main` protegida

## Segredos e segurança

- [ ] Nenhum segredo versionado (verificar alertas de *secret scanning*)
- [ ] Dependabot sem alertas críticos em aberto
- [ ] Endpoints novos com verificação de permissão
- [ ] Senhas armazenadas apenas como hash

## Dados pessoais

- [ ] Nenhum dado pessoal real em testes, evidências ou apresentações
- [ ] Novos campos de dados pessoais registrados no inventário da LGPD

## Licenças e direitos autorais

- [ ] Novas dependências registradas em licenças de terceiros
- [ ] Licenças das novas dependências compatíveis
- [ ] Imagens, ícones e fontes com origem registrada
