# Integridade Acadêmica e Código de Conduta

## 1. Conduta da equipe

- Respeito e cordialidade em reuniões, Issues, Pull Requests e Discussions;
- Críticas direcionadas ao trabalho, nunca às pessoas;
- Compromisso com prazos e comunicação antecipada de impedimentos ao Scrum Master;
- Decisões registradas no GitHub para garantir transparência.

## 2. Integridade acadêmica

- Cada integrante é responsável pelo que envia ao repositório e deve ser capaz de explicar seu código;
- É proibido apresentar como próprio código ou texto de terceiros sem citar a fonte;
- As contribuições individuais são comprovadas pelo histórico de commits, Issues e Pull Requests.

## 3. Uso de ferramentas de Inteligência Artificial

O uso de ferramentas de IA (assistentes de código, geradores de texto) é permitido como apoio, desde que:

- Esteja de acordo com as orientações do professor e da instituição;
- O conteúdo gerado seja revisado, compreendido e validado por um integrante;
- Nenhum dado pessoal, segredo ou credencial seja enviado à ferramenta;
- O uso relevante seja declarado na descrição do Pull Request ou no documento correspondente.

## 4. Descumprimento

Situações de descumprimento são tratadas primeiro em conversa com o Scrum Master e, se necessário, levadas ao professor.
