# Regras de Negócio

> Status: em elaboração. Campos marcados com `[A definir]` devem ser preenchidos pela equipe.

| ID | Regra |
|---|---|
| RN01 | Cada ativo possui um código único |
| RN02 | Apenas usuários ativos podem acessar o sistema |
| RN03 | Não é permitido abrir ordem de serviço para ativo inativo |
| RN04 | Uma ordem só pode ser executada após ser atribuída a um técnico |
| RN05 | Uma ordem concluída ou cancelada não pode ser alterada |
| RN06 | A conclusão de uma ordem exige o registro da descrição do serviço realizado |
| RN07 | Ordens de manutenção preventiva são geradas conforme a periodicidade do plano |
| RN08 | Apenas gestores podem atribuir ou cancelar ordens de serviço |
| RN09 | Prioridades válidas: Baixa, Média, Alta e Crítica |
