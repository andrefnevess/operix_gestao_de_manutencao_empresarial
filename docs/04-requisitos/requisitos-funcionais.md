# Requisitos Funcionais

| ID | Descrição | Prioridade | História |
|---|---|---|---|
| RF01 | O sistema deve permitir que o usuário faça login e logout com e-mail e senha | Alta | UH01 |

| RF09 | O sistema deve exibir o histórico de manutenções de cada equipamento | Média | UH08 |
| RF10 | O sistema deve apresentar indicadores de ordens de serviço e manutenções | Média | UH08 |
