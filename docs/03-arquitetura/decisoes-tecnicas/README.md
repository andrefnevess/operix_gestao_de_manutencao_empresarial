# Decisões Técnicas (ADR)

ADR (Architecture Decision Record) é o registro de uma decisão de arquitetura relevante, com seu contexto, alternativas e justificativa.

## Convenção

- Nome do arquivo: `ADR-NNN-titulo-curto.md`;
- Status possíveis: Pendente de decisão, Proposta, Aceita, Rejeitada, Substituída;
- Usar o modelo [ADR-000-modelo.md](ADR-000-modelo.md).
