# Requisitos — Visão Geral

> Status: versão 1.0.

Este documento resume os requisitos de alto nível. O detalhamento está em [04-requisitos](../04-requisitos).

## Requisitos de alto nível

| ID | Requisito | Prioridade | Histórias |
|---|---|---|---|
| RQ-01 | O sistema deve controlar o acesso por usuário e perfil | Alta | UH01, UH02 |
| RQ-02 | O sistema deve permitir o cadastro de equipamentos | Alta | UH03 |
| RQ-03 | O sistema deve permitir a abertura de chamados e o ciclo completo de ordens de serviço | Alta | UH04, UH05, UH06 |
| RQ-04 | O sistema deve permitir planos de manutenção preventiva com alertas | Média | UH07 |
| RQ-05 | O sistema deve manter o histórico de manutenções por equipamento e apresentar indicadores | Média | UH08 |
