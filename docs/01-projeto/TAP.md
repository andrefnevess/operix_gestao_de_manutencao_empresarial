## 2. Justificativa

A gestão de manutenção em muitas empresas ainda depende de planilhas e comunicação informal, o que causa perda de histórico, falhas não planejadas e custos evitáveis. O projeto propõe uma solução de software que organize esse processo e, ao mesmo tempo, permita à equipe aplicar na prática os conceitos de Programação Orientada a Objetos e de engenharia de software.

## 3. Problema

Ausência de um controle centralizado de ativos, ordens de serviço e manutenções preventivas, resultando em baixa rastreabilidade, atrasos e dificuldade de tomada de decisão.

## 4. Objetivo geral

Desenvolver uma aplicação web para gestão de manutenção empresarial, com cadastro de ativos, controle de ordens de serviço e planejamento de manutenções preventivas.

## 5. Objetivos específicos

- Desenvolver uma aplicação web funcional;
- Implementar o back-end em Java aplicando os pilares de POO (encapsulamento, herança, polimorfismo e abstração);
- Persistir os dados em banco relacional;
- Implementar testes automatizados;
- Utilizar controle de versão com Git e GitHub;
- Implementar pipeline de CI/CD;
- Documentar requisitos, arquitetura e decisões técnicas;
- Conduzir o projeto com Scrum.

## 6. Escopo inicial

- Autenticação e perfis de acesso;
- Cadastro de ativos;
- Cadastro de técnicos;
- Abertura, atribuição, execução e encerramento de ordens de serviço;
- Planos de manutenção preventiva;
- Histórico de manutenções por ativo;
- Relatórios básicos.

## 7. Fora do escopo

- Aplicativo mobile nativo;
- Controle de estoque e compras de peças;
- Integração com ERPs ou sensores IoT;
- Módulo financeiro e faturamento;
- Implantação em ambiente produtivo de cliente real.
