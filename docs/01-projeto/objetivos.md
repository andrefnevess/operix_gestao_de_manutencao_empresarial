## Objetivo geral

Desenvolver uma aplicação web para gestão de manutenção empresarial aplicando Programação Orientada a Objetos e práticas de engenharia de software.

## Objetivos específicos

| ID | Objetivo | Indicador de sucesso |
|---|---|---|
| OBJ-01 | Desenvolver aplicação web funcional | Funcionalidades do escopo publicadas e demonstradas |
| OBJ-02 | Implementar back-end em Java com POO | Modelo de domínio com encapsulamento, herança, polimorfismo e abstração |
| OBJ-03 | Persistir dados em banco relacional | Modelo de dados documentado e implementado |
| OBJ-04 | Implementar testes | Testes unitários e casos de teste documentados |
| OBJ-05 | Utilizar controle de versão | Fluxo de branches e Pull Requests revisados |
| OBJ-06 | Implementar CI/CD | Pipeline executando build e testes a cada PR |
| OBJ-07 | Documentar arquitetura | Diagramas e ADRs publicados |
| OBJ-08 | Aplicar Scrum | Sprints planejadas, revisadas e com retrospectivas registradas |
